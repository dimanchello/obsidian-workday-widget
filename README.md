# ⏱️ Workday Widget

Плагин для [Obsidian](https://obsidian.md), который добавляет панель с таймерами в боковой сайдбар.
Отслеживай рабочий день, обратный отсчёт до событий и любые временные диапазоны — всё в одном виджете.

## ✨ Возможности

### Два типа таймеров

**⏱ Диапазонный** — ежедневный таймер от одного времени до другого.
Подходит для отслеживания рабочего дня, тренировки, учёбы или любого повторяющегося интервала.

- Прогресс-бар заполняется каждый день от начала до конца диапазона
- Показывает сколько прошло, сколько осталось и время окончания
- Автоматически сбрасывается на следующий день

**📅 Обратный отсчёт** — таймер до конкретной даты и времени.
Подходит для дедлайнов, отпусков, релизов и любых событий.

- Показывает дни, часы, минуты и секунды до цели
- Если указана дата начала — отображается прогресс-бар
- При достижении цели появляется кнопка удаления таймера

### Управление таймерами

- **Несколько таймеров** — создавай любое количество
- **Вкладки** — при наличии нескольких таймеров отображаются вкладки с эмодзи
- **Drag & Drop** — перетаскивай вкладки для изменения порядка, порядок сохраняется
- **Запоминание активной вкладки** — при перезапуске Obsidian открывается последний активный таймер

### Настройки каждого таймера

- Название (отображается в тултипе вкладки и в уведомлении)
- Иконка из 30 эмодзи на выбор
- Цвет прогресс-бара через color picker
- Системное уведомление при завершении

### Интерфейс

- Встраивается в боковой сайдбар как стандартный виджет Obsidian (как Calendar)
- Адаптируется под любую тему — использует CSS-переменные Obsidian
- При нехватке высоты появляется вертикальный скролл
- Вкладки поддерживают горизонтальный скролл при большом количестве таймеров

## 📦 Установка

### Вручную

1. Скачай последний релиз со страницы [Releases](../../releases)
2. Распакуй архив в папку `.obsidian/plugins/workday-widget/` внутри своего хранилища
3. В Obsidian: `Settings → Community Plugins → отключи Safe Mode`
4. Найди **Workday Widget** в списке и включи

Итоговая структура:
```
your-vault/
└── .obsidian/
    └── plugins/
        └── workday-widget/
            ├── main.js
            ├── manifest.json
            └── styles.css
```


### Через BRAT (для тестирования)

1. Установи плагин [BRAT](https://github.com/TfTHacker/obsidian42-brat)
2. В настройках BRAT добавь репозиторий: `your-username/obsidian-workday-widget`
3. Включи плагин

## ⚙️ Настройка

Открой `Settings → Workday Widget`.

### Создание таймера

Нажми **+ Добавить таймер** и настрой:

| Параметр | Описание |
|---|---|
| Название | Текст тултипа при наведении на вкладку |
| Иконка | Эмодзи отображаемый на вкладке |
| Тип | Диапазонный или Обратный отсчёт |
| Цвет | Цвет прогресс-бара |
| Уведомление | Системное уведомление при завершении |

### Диапазонный таймер

| Параметр | Пример |
|---|---|
| Время начала | `09:00` |
| Время окончания | `18:00` |

### Обратный отсчёт

| Параметр | Описание |
|---|---|
| Дата начала | Необязательно. Если указана — отображается прогресс-бар |
| Время начала | Время начала отсчёта |
| Дата цели | Дата события |
| Время цели | Время события |

## 🖱️ Использование

### Открыть виджет

- Нажми иконку **⏱️** на левой панели Obsidian
- Или: `Ctrl+P → Workday Widget`

### Переключение таймеров

Нажми на эмодзи-вкладку нужного таймера.

### Изменить порядок таймеров

Перетащи вкладку на новое место — порядок сохранится автоматически.

### Удалить завершённый таймер (Обратный отсчёт)

После достижения цели рядом со статусом появится кнопка 🗑️.
Нажми → подтверди удаление в диалоге.

## 🔧 Разработка

### Требования

- Node.js `>= 18`
- npm

### Сборка

```bash
# Клонировать репозиторий
git clone https://gitflic.ru/project/obsidian_dmitry/obsidian-workday-widget.git
cd obsidian-workday-widget

# Установить зависимости
npm install

# Режим разработки (пересборка при изменениях)
npm run dev

# Продакшн сборка
npm run build
```
